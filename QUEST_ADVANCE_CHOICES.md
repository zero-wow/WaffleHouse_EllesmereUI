# Quest-Advance Choice Database

This database permits a known quest-advance option to be chosen even when an
NPC presents several gossip choices. Entries are deliberately restrictive:
they use the live quest ID plus the exact normalized gossip text. Unknown
choices always remain for the player.

| Quest ID | Quest | Approved advancing choice | Evidence |
| --- | --- | --- | --- |
| 93396 | Bursting at the Seams | Encourage Kifaan to talk to his sister | In-game active-quest dialogue; [Wowhead quest page](https://www.wowhead.com/quest=93396/bursting-at-the-seams) confirms the quest/objective. |

Do not add a branch merely because its Wowhead description sounds linear.
Wowhead quest pages do not expose the live gossip option IDs or all branch
labels. Add an entry only from an observed in-game option paired with its
active quest ID.
